# Sources

## Primary Sources
- [FIRST CVSS v4.0 Specification](https://www.first.org/cvss/v4.0/specification-document): Forum of Incident Response and Security Teams (FIRST). Released November 2023. Authoritative specification for CVSS 4.0 metrics, scoring, and nomenclature.
- [FIRST CVSS v4.0 Calculator](https://www.first.org/cvss/calculator/4.0): Reference implementation and interactive calculator.

## Secondary Sources
- [NVD CVSS v4.0 Documentation](https://nvd.nist.gov/vuln-metrics/cvss): National Vulnerability Database guidance on CVSS v4.0 adoption.
- [CVSS v4.0 User Guide](https://www.first.org/cvss/v4.0/user-guide): FIRST supplementary guidance on metric interpretation.
