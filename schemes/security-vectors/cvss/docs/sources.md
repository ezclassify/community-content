# Sources

## Primary Sources
- [FIRST.org CVSS v3.1 Specification](https://www.first.org/cvss/v3.1/specification-document): Common Vulnerability Scoring System v3.1 specification defining Base (Section 2), Temporal (Section 3), and Environmental (Section 4) metric groups

## Secondary Sources
- [FIRST.org CVSS v3.1 Calculator](https://www.first.org/cvss/calculator/3.1): Interactive calculator with metric definitions
- [NVD CVSS Guidance](https://nvd.nist.gov/vuln-metrics/cvss): NIST NVD implementation guidance
