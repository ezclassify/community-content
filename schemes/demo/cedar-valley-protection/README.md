# Cedar Valley: Protection

A small fictional teaching example with one required category and four protection levels. Protection rolls up by maximum sensitivity for display and handling. The companion access policy separately compares a trusted host-provided clearance; deployments still supply identity, purpose, and record relationships.

**Source:** [`scheme-folder/schemes/cedar-valley-protection@1.0.0.yaml`](../../../scheme-folder/schemes/cedar-valley-protection@1.0.0.yaml)

## Worked example

```text
Input A: INTERNAL
Input B: CONFIDENTIAL
Rollup:  CONFIDENTIAL
```

PUBLIC is positive approval for the exact version. An unmarked file is not public. This is a fictional policy, not a real district standard.
